> **HOW TO READ AND UPDATE THIS CHANGELOG:**

> This document follows a modified [Keep a Changelog](https://keepachangelog.com/) format adapted for the R/JASP ecosystem. Releases are listed in reverse chronological order (newest first).

> * **Issue References:** Please reference the relevant GitHub Issue (if any) at the end of your line (e.g., `([Issue #19](https://github.com/jasp-stats/jaspModuleTemplate/issues/19)`).

>   * **Changed:** Updates to default configurations, boilerplate code, or dependencies. 
>   * **Fixed:** Bug fixes in the build pipeline, R wrappers, or QML layouts.
>   * **Deprecated / Removed:** Outdated template components or legacy code.

# jaspQualityControl (development version)

## Added
* Process Capability: optional Z.bench (ST) / Z.bench (LT) columns, reporting the sigma level based on the total expected defect probability across both specification limits, alongside the existing Z (ST) / Z (LT) = 3·Cpk / 3·Ppk.
* Process Capability / control charts: added "Pooled" as a within-subgroup standard deviation estimation method (in addition to R-bar and S-bar).
* DOE Analysis: optional confidence intervals for the effects and coefficients in the coefficients table ([Issue #4640](https://github.com/jasp-stats/jasp-issues/issues/4640)).
* DOE Analysis: the ANOVA table splits the Error row into Lack of fit (with F-test) and Pure error when the design has replicated runs, e.g. center points ([Issue #4640](https://github.com/jasp-stats/jasp-issues/issues/4640)).
* DOE Analysis, response optimizer: optional table with the predicted responses at the optimal solution (and at manually set factor levels), with standard error, confidence interval for the mean response and prediction interval for a single new run ([Issue #4640](https://github.com/jasp-stats/jasp-issues/issues/4640)).

## Changed
* DOE Analysis, Factorial Design and Response Surface Design: help moved from markdown files into the QML `info` properties.
* DOE Analysis: the contour plot is now drawn with ggplot2 instead of base graphics, so it renders correctly in interactive (plotly) mode, and always shows its legend. The "Show legend next to graph" option was removed; surface plots no longer show a color legend.

## Fixed
* Gauge r&R: the range and average charts by operator (and their test tables) are now updated when the operator, part or measurement variables or the data format change, and are removed when Type 3 study is ticked; previously they kept the old grouping, limits and test violations.
* Control charts for attributes: with unequal subgroup sizes, the out-of-control test table of the u, Laney p' and Laney u' charts checked test 1 (beyond limit) against the first subgroup's limits only, so it could list points that the plot shows within their limits and miss points beyond them. Test 1 now uses each subgroup's own limits. The p chart table never reported test 2 (shift) or test 3 (trend), with equal or unequal subgroup sizes, because each subgroup was tested on its own; these tests are now evaluated on the whole series of plotted proportions, as for the other charts. The tables of the np, c, u and Laney charts with constant limits and of the individuals and moving range charts are unchanged.
* Process Capability: Box-Cox transformation with λ < 0 and no continuity adjustment now uses y = −(x + shift)^λ, so the lower and upper specification limits keep their roles. Previously the transformed limits were swapped, which stopped the analysis (both limits) or gave capability indices and ppm for the wrong tail (one limit). Results now equal those with the continuity adjustment.
* Process Capability: the non-normal capability analysis with the logistic distribution now accepts negative measurements; previously any negative value stopped the analysis with "Dataset contains negative numbers", although the logistic distribution covers all real values.
* Control charts for attributes: the p chart no longer shows a negative lower control limit. When the subgroup sizes differed by at most 25%, it drew constant limits from the average subgroup size, centred on the unweighted mean of the subgroup proportions instead of the centre line and not bounded to [0, 1], while the out-of-control test used the limits of each subgroup, so the plot and the test could disagree. The limits are now always computed for each subgroup's size around the pooled proportion and bounded to [0, 1], as in Minitab; with unequal sizes they are drawn as steps. The upper control limit of the Laney p' chart is capped at 1 ([Issue #3225](https://github.com/jasp-stats/jasp-issues/issues/3225)).
* DOE Analysis: for saturated models (no error degrees of freedom) of two-level factorial terms, the Pareto chart and normal plot show the effects with Lenth's pseudo standard error and margin of error instead of failing; other saturated models (e.g. with squared terms) and plots without effects give an error ([Issue #3861](https://github.com/jasp-stats/jasp-issues/issues/3861), [Issue #4158](https://github.com/jasp-stats/jasp-issues/issues/4158)). The normal plot of effects now ranks the effects by their value (some points had the percentile of another effect). Without alias names, the effect plots no longer squeeze the chart to the right (term labels are decoded before the layout is made), and the reference line of the normal plot no longer runs along the top edge for large effects.
* Probability of detection: the confidence band of the detection plot used the one-sided critical value, so a band labelled 95% was a 90% interval. It is now a two-sided interval at the chosen level (computed on the link scale and back-transformed) and therefore wider; the fitted curve and all tables are unchanged.
* Process Capability: with stages, the probability plot (also in the report) now fits the line and confidence bands to each stage's data; previously every stage showed the fit of the last stage.
* Process Capability: the 95% confidence bands of the Weibull probability plot (also in the report) now use the standard normal critical value (1.96); previously they used 1.31 and covered only about 80%.
* Process Capability: the confidence bands of the probability plot no longer disappear for data that vary on the order of 0.001 (e.g. measurements in small units); the numerical derivatives now use steps relative to small fitted parameters.
* Process Capability: the Anderson-Darling p-value in the probability table now always follows D'Agostino & Stephens (1986) for the modified statistic. For a statistic just below 0.6 whose modified value is at least 0.6 (small samples), it previously reported the much larger p-value for known parameters; for very large statistics it no longer becomes larger than 1, infinite or NaN.
* Process Capability: the confidence intervals for Cp and Cpk in the process capability (within) table used the wrong degrees of freedom (subgroup size and number of subgroups were swapped, and the within std. dev. method was ignored), so the intervals were too narrow in the usual case of more subgroups than observations per subgroup. The degrees of freedom now follow the method used to estimate the within std. dev.: pooled Σ(nᵢ − 1), R-bar 0.9·Σ(nᵢ − 1), S-bar f(n̄)·Σ(nᵢ − 1), and the number of complete moving ranges for individuals. With a historical std. dev., these intervals are no longer shown.
* Control charts for attributes: the Laney p' and u' charts standardized every subgroup with the first subgroup's size, so with unequal subgroup sizes the control limits were wrong and depended on which subgroup came first. Each subgroup is now standardized with its own size (Laney, 2002); results with equal subgroup sizes are unchanged.
* Time weighted charts: singleton subgroups across multiple measurement columns now use moving ranges in row order, preserving entirely missing rows as gaps.
* Process Capability: missing moving ranges no longer discard the capability tables or the report. A control chart that cannot be drawn is left out with a note below the plot (or the plot shows the error if neither chart can be drawn); on the report, it is replaced by its error. Unavailable within standard deviations remain missing while overall estimates are retained.
* Time weighted charts, variables charts for individuals: when the std. dev. is estimated from moving ranges and a stage (or the data) has no complete moving range (fewer non-missing observations than the moving range length, or every range interrupted by a missing value), the chart shows an error naming the stage instead of stopping the analysis or drawing NaN limits. In the reports, only the affected chart is replaced by its error.
* Time weighted charts: the EWMA chart estimates the std. dev. of individual observations with missing values from moving ranges, like the CUSUM chart (previously it stopped with an error, or, with a grouping variable or across-rows data, drew zero-width control limits).
* Time weighted charts: after a subgroup without observations, the CUSUM and EWMA charts continue from the last observed subgroup with finite control limits (previously both lines stopped at the gap and the EWMA limits became infinite).
* Time weighted charts: notes about removed observations (not assigned to a stage or subgroup) are shown below the charts.
* Time weighted charts: the chart tables no longer stay in the output when the report is shown.
* Time weighted charts: the CUSUM moving range length field is shown based on the CUSUM (not the EWMA) std. dev. source.
* DOE Analysis: with "Display results in coded units", discrete factors with more than two levels were coded as one numeric column with evenly spaced values from -1 to +1 (1 df instead of k-1), which gave wrong ANOVA, lack-of-fit test, S, R², p-values and effects. They now stay factors (sum-to-zero contrasts), as in uncoded units, and the manual low/high table shows "Not available" for them and for blocks (whose low/high levels were already ignored). Levels without runs are named below the coefficients table. Also affected the response surface ANOVA with "Use coded data to calculate squared terms" and stepwise selection on coded data ([Issue #4638](https://github.com/jasp-stats/jasp-issues/issues/4638)).
* DOE Analysis: aliasing removed whole terms when only some of their contrasts were aliased, e.g. discrete factors with levels -1/0/1 where level 0 only occurs at the center points (the model reduced to one factor), or an interaction A ✻ F where A is constant within one level of F. Only the aliased contrasts are now left out; the term keeps its estimable contrasts (with fewer df) and a footnote names it, plus a hint to enter factors with a shared center level as continuous predictors. Type III sums of squares are not defined for such models, so the ANOVA table then shows an error asking for Type I or II. Coefficients and effects that depend on which aliased contrasts are left out (e.g., on the order of the factor levels) are left empty, and the regression equation is then not shown. The response optimizer, prediction tables and optimization plot only use settings whose response the data can estimate (e.g., not combinations of factor levels without runs), and show an error when they find none (e.g., a factor held constant within blocks); contour/surface plots without a unique prediction, and Pareto and normal effect plots without a unique effect, also show an error. Alias footnotes in coded units now come from the coded model, and VIF gets a footnote when it is not available.
* DOE Analysis, factorial designs: with "Display results in coded units" off, the ANOVA treated every continuous predictor as a factor. Center points made all but one term look aliased (e.g. only the first factor left in the ANOVA), and a predictor with many distinct values gave the error "residual df = 0". The ANOVA now uses the predictors in coded units, so it is the same in coded and uncoded units; a continuous predictor with 3 levels has 1 df instead of 2. When coding changes the model (an interaction or squared term without its main effects), the uncoded ANOVA uses the uncoded fit, so it agrees with the coefficients and Model Summary, and the Effect column (which comes from the coded fit) is left empty. A footnote says which units the uncoded ANOVA uses.
* DOE Analysis: a model without error degrees of freedom shows sequential sums of squares; the ANOVA table now labels them Type I instead of the selected type and says why.
* DOE Analysis: the VIF column of the coefficients table showed the VIF of a main effect for interaction terms and nothing for squared terms; each coefficient now shows the (generalized) VIF of its own term.
* DOE Analysis: with type II/III sums of squares, the ANOVA table's Model and Total rows no longer just add up the individual term SS (which is only valid for type I). Model SS is now SST − SSE, with F/p from the overall regression test, and Total SS is SST. The grouped rows (Linear, Squared, Interaction terms, Covariates) are now tested jointly and report MS, F and p.
* Test–retest: limit across-rows input to two measurement columns, reject extra single-column measurement sets (previously the third set was silently ignored) and report duplicate or unmatched readings; rows with missing values are still excluded.
* Attribute agreement: with more than one trial, Kendall's tau stopped with an error (with a standard) or showed extra rows (without a standard). Appraiser vs standard is now Kendall's tau-b of each trial with the standard, averaged over trials (as in Minitab); between appraisers it is Kendall's tau-b over all combinations of the two appraisers' ratings of each part, so it does not depend on the trial order. Results with one trial are unchanged. Without a standard, the empty standard column is no longer shown ([Issue #4677](https://github.com/jasp-stats/jasp-issues/issues/4677)).
* Attribute agreement: return valid confidence-interval endpoints for zero or perfect agreement.
* Attribute agreement: in wide format, "Between appraisers", "All appraisers vs standard", Fleiss' kappa between appraisers, the Cohen's kappa correlations and, with a single trial, Kendall's tau compared the appraisers' ratings by row position, so data in run order (rows not sorted by part within every appraiser) gave wrong agreement. Ratings are now matched by part. In both formats, a design in which an appraiser does not rate every part, or rates a part more often than another, and a part whose reference differs between rows, now give an error instead of wrong results or a crash ([INTERNAL-jasp#2812](https://github.com/jasp-stats/INTERNAL-jasp/issues/2812)).
* Attribute agreement: with more than one trial, the correlations between appraisers paired trial k of one appraiser with trial k of another, so they changed with the trial order (e.g. after reordering the rows of long-format data). They now pair all ratings of the same part; results with one trial are unchanged. The table, previously titled "Cohen's kappa correlations summary", is renamed "Correlations between appraisers' ratings", as it shows Pearson correlations of the ratings, not kappas. Appraiser names that are numbers or contain spaces or punctuation (e.g. `1`, `B L`) now show their values instead of empty columns, and a correlation of exactly 1 is shown instead of "-". In long format with more than one trial, a footnote to Fleiss' kappa vs standard (averaged over trials, as in Minitab) says that trial k is the k-th row of an appraiser and part ([Issue #4678](https://github.com/jasp-stats/jasp-issues/issues/4678)).
* Probability of detection: identify natural-log coordinates in covariate labels, reference tables and explanatory footnotes.
* Attribute charts: allow defect rates above one and reject defective-item counts exceeding the sample size.
* Process Capability: observed nonconformance rates and changes from baseline now use each stage's valid measurement count when stage sizes differ.
* Attribute charts: label u and Laney u axes as defects per unit instead of proportions.
* Multivariate control charts: keep exported T² values aligned with their original rows when incomplete observations are omitted.
* Multivariate control charts: fix Phase II errors and missing observation labels caused by automatic naming.
* Control charts and process capability: prevent overflow when calculating bias-corrected standard deviations.
* Control charts with stages: the test results tables now report the chart position and timestamp of out-of-control points in every stage after the first, instead of their position within the stage ([Issue #4672](https://github.com/jasp-stats/jasp-issues/issues/4672)).
* Control charts with interleaved stages (stages alternating between rows): x-axis labels and test results timestamps now belong to the plotted subgroup in "Across rows" data and in time weighted charts with timestamps.
* Cumulative sum charts with stages: the names of the stages after the first are now shown halfway along their stage instead of at its last point.
* Control charts, time weighted charts and process capability: the unbiasing constants d2 and d3 for subgroup sizes or moving range lengths above 50 are now computed exactly instead of by a polynomial approximation that was wrong beyond 100 (e.g. d2 = 5.64 instead of 14.3 for n = 250), so R-bar and moving range based std. dev. and control limits are correct for large subgroups.
* Time weighted charts: the exponentially weighted moving average chart now offers S-bar and R-bar as std. dev. estimation method for data in wide format ("Across rows"), instead of only X-mR, which stopped the analysis with two or more measurement columns.
* Rare event charts: the interval type "Time" no longer always fails with "Date/time conversion returned no valid values", and its intervals are always converted to minutes, so the chart no longer labels intervals given in hours as minutes.
* Rare event charts: the G chart probability limits are corrected. The LCL is 0 whenever the event probability is at least 0.00135 (it was slightly above 0, so every gap of 0 was flagged by test 1), and the UCL and center line are no longer sometimes one unit too high (e.g. the center line for event probability 0.5 is 0 instead of 1). All limits are bounded below by 0, the smallest possible gap.
* Stepwise model selection in the Response Surface design now respects marginality: a squared term is no longer retained without its corresponding main effect.
* Process Capability: distribution/fit density curves no longer render flat in interactive (plotly) plots; the curves are now drawn with `geom_line` instead of `stat_function`.
* Gauge r&R (crossed): with "Fixed effects" as type of model for the F-statistic, the p-values for Part and Operator in the ANOVA table with interaction now use the repeatability degrees of freedom (the error term of their F-statistics) instead of the interaction degrees of freedom, which gave incorrect p-values. A Type 3 study with this setting no longer stops with an error.
* Process Capability: the x-axis of the capability plot is no longer stretched towards the default historical scale (Weibull) or log mean (log-normal) when no historical parameter is set, which squeezed the histogram and fitted density into a narrow strip for data far from zero.
* Process Capability: the x-axis of the Weibull and log-normal probability plots no longer stretches far beyond the data, which squeezed the points into a thin strip and made the tick labels overlap. The axis now follows the data, and ticks that would crowd each other are dropped.
* Attributes agreement analysis: Fleiss' kappa no longer crashes with newer `irr` (>= 0.85) when a within-appraiser input has a single measurement column; returns NaN as before.
* DOE Analysis: the Effect column of the coefficients table is now 2 × coefficient (on the −1/+1 scale) for main effects and interactions of every order. Previously 2-way and 3-way interactions were inflated (4× and 6×), effects depended on the factor level labels, and uncoded continuous predictors and manual coding beyond ±1 gave wrong values. Effects are left blank for squared terms and factors with more than two levels, and a footnote explains the definition ([PR #525](https://github.com/jasp-stats/jaspQualityControl/pull/525)).
* DOE Analysis: no longer crashes when a discrete factor is fully removed from the model due to aliasing ([PR #525](https://github.com/jasp-stats/jaspQualityControl/pull/525)).
* DOE Analysis: the response optimizer now uses the observed maximum (maximize) or minimum (minimize) as the default target when "Set all bounds manually" is on and "Set all targets manually" is off. Previously the target silently became the value of the disabled Upper/Lower field (1 or 0), which distorted the desirability. Settings without a defined desirability (maximize with the lower bound above the target, minimize with the target above the upper bound, target outside manual bounds, lower above upper) now give an error instead of a misleading optimum. A target outside bounds taken from the data gets a footnote, and a bound equal to the target no longer gives NaN. The optimizer now starts from the first run and the three design points with the highest desirability instead of only the first run, so it no longer stalls at desirability 0 when a design point already reaches the bounds. A footnote flags a solution with desirability 0; acceptable settings that lie between the design points can still be missed. The optimizer is no longer rerun when unrelated options change. Analyses with a single predictor no longer crash, the settings footnote no longer reports an entered target as estimated from data, no empty "Optimization Plot" heading remains after a settings error, "Show optimal solution" now also hides the settings table, and an optimum on the edge of the design space is no longer flagged as extrapolation ([PR #541](https://github.com/jasp-stats/jaspQualityControl/pull/541)).
* DOE Analysis, response optimizer: with blocks or covariates in the model, the fitted responses and desirabilities added every block and covariate coefficient in full. Predictions are now averaged over the blocks and covariates are held at their mean, matching the new prediction table ([Issue #4665](https://github.com/jasp-stats/jasp-issues/issues/4665)).
* DOE Analysis, response optimizer: with two or more discrete factors, the optimization plot, its summary table and the solution table's fitted response gave some factor levels no contribution (e.g. the last level of the first factor), because the factor levels were merged. The optimal settings themselves were not affected ([Issue #4665](https://github.com/jasp-stats/jasp-issues/issues/4665)).
* DOE Analysis: block and discrete factor levels without runs (e.g. all their rows filtered out or with missing responses) are dropped. Such a level made the model fall back from sum-to-zero to treatment contrasts, which the effects and the response optimizer assume.
* Gauge r&R: the gauge evaluation table of the report shows the name of the operator variable instead of its internal (encoded) column name.
* Control charts: the CL, LCL and UCL labels of values of 1000 or more keep all their decimals (e.g. 1908.333 instead of 1908.33); the shortened labels could also be rounded wrong (2092.49 instead of 2092.495).
* Process Capability, stages: the Cpm confidence interval is no longer blanked for the stages after the baseline, and the change row no longer shows the difference of the interval bounds as an interval.
* Process Capability, stages: the change (vs. baseline) rows are computed from the unrounded values, so they are the rounded difference; the difference of the rounded values could be off in the last decimal.
* Process Capability: for data with a small spread (std. dev. or log std. dev. below ~0.002, e.g. 10.000 ± 0.001), the logistic fit and the log-normal fit with a historical parameter no longer fail. The 95% confidence bands of the normal and log-normal probability plots are now computed accurately for small and large spreads; previously their variance estimates could be off by ~3% (e.g. std. dev. 0.02), and the bands were missing or wrong for very large spreads (e.g. std. dev. 100000). Other logistic estimates can change in the 4th–5th significant digit.
* Process Capability, rare event (t) charts: Weibull, gamma, log-logistic and 3-parameter Weibull fits no longer fail for data in very small or large units (e.g. Weibull data in thousandths, gamma data in hundred-thousands), and their estimates no longer change with the unit. A 3-parameter Weibull fit with a shape of at most 1 gives an error instead of arbitrary estimates (the likelihood then increases towards a threshold at the smallest observation, so there is no maximum likelihood estimate). The Weibull probability plot confidence bands no longer depend on the unit either (they were off for data in large units), and the Weibull probability table uses the same fit as the plots (a failed fit shows an error on the table). The gamma fit now solves its likelihood equations directly, so it is the exact maximum likelihood estimate also for data with little variation (e.g. 10 ± 0.02), where the previous fit could be off by several percent in the shape and hence in the expected ppm. Other estimates can change in the 4th–5th significant digit (for the Weibull fit, closer to the exact maximum likelihood estimate).
* Process Capability: the histogram density line for the log-logistic distribution now uses the log-logistic fit (it used the logistic fit, which drew an essentially flat line); a failed fit is shown on the histogram instead of stopping the analysis.
* Process Capability, non-normal: Pp, PpL, PpU, Ppk and the observed and expected ppm use the specification limits as entered; they used the limits rounded to the displayed decimals (e.g. 0.0144 as 0.014), which changed the results for limits with more decimals, such as measurements in small units.
* Process Capability: with the Kaplan-Meier rank method, the probability plot (also in the report) no longer places the largest observation at p = 1, which drew it on the upper edge of the panel; it is now placed at 90% of the distance between the previous plotting position and 1, i.e. (n - 0.1) / n without ties (a tied maximum already lies below 1 and is unchanged). The y-axis of the probability plot now extends past the 0.1% and 99.9% ticks when points fall outside them (large samples), instead of leaving those points out.
